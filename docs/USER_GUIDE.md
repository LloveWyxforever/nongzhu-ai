# 农助 AI 使用说明

## 1. 启动与关闭

1. 双击项目根目录 `start.bat`。等待显示本地服务就绪。
2. 浏览器打开 http://127.0.0.1:5173 。默认首页含真实功能入口、示例农场和农事安排。
3. 检查状态使用 `check.bat`；关闭项目使用 `stop.bat`。关闭网页不会停止后端。
4. 端口 5173、8017 已被其他程序占用时脚本会报错，不会强行终止其他程序。日志在 `logs/`。

## 2. 接入 DeepSeek

在项目目录将 `.env.example` 复制为 `.env`，用记事本填写 `DEEPSEEK_API_KEY`。保持模型为 `deepseek-chat` 或填写您实际可用的模型。运行 `stop.bat` 再运行 `start.bat`。

系统设置页的“已配置”仅代表读取到密钥，不代表余额、网络和模型权限已核验。请发送一次普通农业问题进行实际验证。您需要自行获取密钥、确认收费，不应把密钥发送到对话或写入前端文件。

文字、地块档案及相关知识片段会发送给配置的模型。图像需要额外配置 `VISION_API_KEY`、`VISION_BASE_URL`、`VISION_MODEL`，并在每次带图对话勾选同意发送图片。DeepSeek 文本接口不被当作视觉模型使用。

## 3. 使用全局数字人

页面右下方的原创数字助手“小禾”始终可用。拖动形象可调整位置，不能拖出屏幕；鼠标与触摸均支持。位置保存在当前标签页会话中，切换页面保持，窗口大小改变会重新限制边界。

点击形象展开对话；点击关闭按钮收起，已存在的对话不会因为面板收起而卸载。数字人待机、思考、回答使用不同动画。键盘聚焦数字人后 Enter/空格切换面板，方向键移动。

对话默认关联当前选中地块；上下文栏显示地块。使用麦克风前请了解浏览器厂商可能使用在线语音服务。若当前浏览器不支持语音识别，可继续输入文字。语音播报取决于系统中文语音包，可点击停止。

## 4. 管理 3D 农场

从导航进入“3D 数字农场”。左键拖动旋转，滚轮缩放，右键拖动平移；触屏可使用手势。支持视角重置、缩放按钮和浏览器全屏。

点击作物地块后右侧显示独立档案；颜色表示档案状态。点击地块“编辑”修改作物、地区、面积、日期、阶段、状态、备注和模拟标记。新增档案会创建三维地块。作物生长表现由手动记录阶段决定，不是实时测量。

点击总览中的田地可进入该地块的独立三维细节场景，查看田垄、植株茎叶以及对应阶段的穗或果实。现有模型样式参考用户提供的“3D数字农田-代码(1).zip”：厚土层草坪底座、木框田块、木篱笆、木桶、浇水壶、渐变天空、暖色阴影与弯曲叶片。小麦、玉米、胡萝卜、番茄、南瓜使用参考中的程序化模型；蔬菜暂用瓜类示意，水稻和豆类等使用通用禾本科示意，并标记“通用示意”，不代表准确作物形态。可继续旋转、缩放、平移，点击“返回全场”恢复农场总览。右侧档案仍对应选中地块，修改作物或阶段后细节模型会随档案更新。模型株数、大小、田垄数量和装饰仅作示意，不代表真实种植密度、实测地形或设备数据。参考游戏中的金币、天气模拟和加速生长未接入真实管理档案。

“农事记录”页签创建和完成任务。“分析历史”显示关联地块的专业 Agent 结果与失败状态。“种植管理建议”“异常与风险分析”“销售与政策咨询”会打开关联地块的真实 AI 对话。

AI 回答下方可“保存为管理计划”，保存到地块任务历史，执行前应人工审核。自行安排的农事也可在首页或种植管理页新增。

如果 WebGL 不可用或场景运行出错，使用地块列表；也可主动点击“地块列表”切换。示例场景的全部地块在首次启动时明确标注为模拟档案。替换为真实档案不意味着获得真实传感器或遥感数据。

## 5. 多智能体协作

农业总问答现已直接嵌入“农业首页”，侧栏不再单独显示“AI 智能助农”。首页可直接输入各类农业问题、跨领域协作问题，并查看总问答历史。默认不关联具体地块，可用问答上方的下拉框选择档案。旧的 `#chat` 链接会转入首页。三个专业对话入口保留，首页专业卡片也直接进入对应栏目。

侧栏“种植管理”“病虫害与风险”“产业助农”直接进入对应专业对话。各专业仅检索适用分类资料、显示自身快捷问题并使用独立历史。无关问题要求拒答并引导至正确入口；跨领域需求进入“AI 智能助农”。专业知识由独立知识框架和您导入的分类资料组成，不代表已建立或验证完整权威知识库。实际回答需要配置模型并核验。

种植管理页的“作物档案与农事”按钮可打开原有管理功能。顶部“工作空间”返回首页，页面下拉框切换栏目，连接状态按钮重新检查服务，头像按钮打开档案。

体验园操作面板右上角箭头可收起/展开，不影响存档和生长。地块列表选中田地后进入该田三维近景；顶部“此田 3D 模型”可从列表返回模型。如果上下文丢失或模型加载失败，可点击重新加载，错误原因会在场景区域显示。

### 互动种植体验园

农场上方切换“互动种植 · 模拟”，可管理 16 块体验田。点击三维田块或操作面板中的编号进入单田；空地可选择小麦、玉米、胡萝卜、番茄、南瓜播种。播种后显示生长百分比与模拟水分，浇水补充 35%，并播放短暂水滴动画。水分降到 10% 时暂停生长，补水后继续；达到 100% 后收获，空出田块再次播种。成熟需约 2.5 至 5 分钟有效生长时间，这只是互动模拟，不是实际农业周期。

操作、进度和累计收获保存在 SQLite 独立体验园表中，每 2 秒同步。关闭页面后按经过时间及剩余水分计算有限生长，不会在缺水后无限增长。最近播种、浇水和收获记录可在面板展开查看。体验园不修改真实地块作物档案、不生成实际农事记录。点击面板返回按钮恢复体验园总览；切回“档案农场”继续原有地块管理。

自然语言中的种植、生长、病虫、异常、政策、销售等需求由中枢路由到对应专业 Agent。跨领域问题调用多个 Agent；专业结果随后由总智能体综合。界面显示各 Agent 的进行中、完成、失败状态。

信息不足时会提出追问；勾选需要补充的问题并填写具体情况后继续发送。可以查看历史对话、复制、重新生成和评价回答。Agent 协作中心显示真实执行记录，不填充假日志。

目前采用透明的关键词路由，并非复杂的自主规划引擎。农业判断仅供辅助，异常不能当作专家确诊。药械操作应遵循标签说明与当地农技人员指导。

## 6. 知识库与附件

知识库页面选择分类，填写资料原始来源，再导入文件。支持 PDF、DOCX、UTF-8 TXT、Markdown、JSON，限 15 MB。扫描件没有 OCR，无法提取文字时会明确报错。检索建议输入至少 3 个汉字或字符；Agent 回答显示命中资料来源。资料来源由用户填写，未自动鉴真。

对话支持 JPG/PNG/WEBP（限 8 MB）、MP4/WEBM（限 30 MB）上传和本地预览。图片可移除。视频关键帧分析尚未实现，不会声称识别视频。仅选择附件不会将文件发送给模型服务。

## 7. 备份

先停止项目，再备份 `data/`、`knowledge/`、`.env`。`.env` 含密钥，请妥善保存。不要把包含密钥或个人数据的目录提交到公开仓库。

P2 精细作物模型、季节变化、真实气象映射和更多玩法均待扩展。当前版本未配置网页搜索、可靠实时市场或官方政策查询服务，不编造这些数据。

### 首页布局与导航收放（2026-11-13）
- 电脑端点击顶部左侧的导航收放按钮，在完整导航与图标导航之间切换；悬停图标可查看入口名称，收放偏好在本机保留。
- 手机端点击顶部菜单展开导航，可通过侧栏关闭按钮、遮罩或 Escape 键收起，选择页面后自动收起。
- 首页以农业总问答为主体，保留关联地块、对话历史、上传、语音等原有功能。介绍、专业智能体、农业空间统计、3D 农场预览和农事安排仍可在问答下方使用。
- “开始智能对话”及“与农助 AI 聊一聊”可定位并聚焦首页输入框；“查看全部农事”进入作物档案与农事。

### 首页仅保留问答与可选日历（2026-11-13）
此项取代前面的首页概览布局：首页移除宣传、统计、专业卡片和农场预览，只保留总问答；专业咨询、3D 农场等仍从导航进入。
点击问答标题旁“农事日历”可展开或收起日历。日历支持上月/下月、回到今天、选择日期、查看当天关联地块任务、勾选完成和新增当天农事。新建任务需要至少一个地块，保存与完成状态沿用后端 SQLite 农事接口。手机端日历覆盖在对话区右侧，可点击关闭继续对话。

### 农业工作台与导航精简（2026-11-13）
- 删除“认识农助 AI”按钮与“Agent 协作中心”入口、页面；原 #agents 地址返回首页。地块自身的分析历史仍保留。
- 点击侧栏“我的农业工作台”打开工作台。导航收起后仍保留工作台图标入口，顶部页面选择器也能进入。
- 农具展示支持选择手铲、浇水壶、修枝剪、育苗盘、量杯，查看用途与养护并加入农事安排。图示陈列不代表真实设备。
- 配制计算只换算用户提供的单一液体制剂标签倍数：制剂体积=最终药液体积/稀释倍数，加水至最终体积。未设置推荐药剂或浓度；不适用于粉剂、多药混配等。可保存为待核对农事，需要已有地块。

### Kindred 风格界面（2026-11-13）
- 整体采用暖白纸色、黑灰文字、黑色圆角按钮和简洁导航；保留中文功能及农场作物、状态辨识色。
- 首页未开始对话时显示实时 Canvas 点阵双手，基于指定 Higgsfield 图片亮度生成横向扫描点阵，包含缓慢呼吸、漂移、手势溶解与行错位。开始对话后移除背景，保证消息阅读。
- “开始农业对话”聚焦输入框，按钮下方带柔和彩虹微光。没有加入虚构合作商标或替换为 Kindred 品牌。
- 图像匿名跨域加载；加载或像素读取失败时隐藏装饰背景，对话功能继续可用。系统设置减少动态效果时固定画面；后台页面停止绘制，手机降低刷新频率。

### 农场天气与病虫害模拟
场景左下角新增独立的“天气模拟”和“病虫害模拟”按钮。天气支持晴天、阴天、降雨、降雪，可恢复晴天。病虫害可选择地块、类型与强度，点击开始进入目标地块详情，显示飞虫或病斑示意及地块标记；可清除模拟。返回全场后仍能看到目标地块的效果，切换档案/互动种植模式会清除病虫害效果。所有效果仅当前页面可视化，不修改地块状态、土壤水分、生长进度或数据库，不代表实时天气与诊断。列表备用视图可设置选项，3D 效果需返回模型查看。

### 扩展服务能力（2026-11-14）
- 系统设置下方增加 Open-Meteo 地区选择、当前天气与三日预报，以及 Bing 网页摘要检索。无需新增密钥，外部服务失败会显示错误。市场价格不作为已核验行情，政策须查看原始来源。
- 对话中包含“搜索”“查询价格”“市场价格”“最新政策”时，后端尝试网页检索并将来源交给智能体，检索失败不编造来源。
- 上传视频后可点击“提取关键帧”，本机取 10%、50%、90% 三个位置，支持最长十分钟。发送视觉模型需勾选授权，并配置 VISION_API_KEY、VISION_BASE_URL、VISION_MODEL。DeepSeek 文本密钥不等于视觉模型能力。
- 语音输入使用聊天输入区的麦克风按钮并允许浏览器权限，回答后的扬声器按钮用于播报，浏览器不支持时提示使用文字。
