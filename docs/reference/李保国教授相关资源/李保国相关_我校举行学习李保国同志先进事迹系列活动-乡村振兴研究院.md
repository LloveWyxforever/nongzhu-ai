## 网页正文（剔除导航及图片）

4月10日是“人民楷模”李保国同志逝世10周年纪念日，我校隆重举行学习李保国同志先进事迹系列活动，深入学习贯彻习近平总书记对李保国同志先进事迹的重要批示精神，树立和践行正确政绩观，落实立德树人根本任务，奋进乡村全面振兴新征程。

农业农村部中国农村技术开发中心主任孙传范、省科学技术厅二级巡视员杜月昌、省农业农村厅副厅长孙晨光、邢台市委副书记陈冲、全体校领导及李保国同志家属出席有关活动。中国农村技术开发中心、省科学技术厅、省农业农村厅有关部门，邢台、保定、唐山部分区县及服务基地代表，优秀科技特派员河北巡讲团成员，李保国教学科研团队成员，“李保国式党支部”“李保国式教师团队”“李保国志愿服务队”代表及师生代表共计3000余人参加相关活动。

上午9:00，主纪念活动在西校区李保国纪念广场举行。与会同志重温习近平总书记对李保国同志先进事迹的重要批示。河北农业大学及李保国教授生前服务基地代表，向李保国纪念石敬献花篮。大家集体面向李保国同志雕像默哀致敬。

党委书记张立杰在讲话中表示，10年来，学校始终牢记习近平总书记殷切嘱托，让李保国同志的高尚精神和模范行动融入血脉、见诸行动，引导鼓励支持更多师生投身脱贫攻坚、乡村振兴主战场，组建跨学科、跨领域师生服务团队，在全省建立社会服务基地平台近300个，打造了9大乡村产业振兴典型示范场景，推广科技成果800余项。“农业创新驿站”模式先后入选全国产业扶贫典型案例和全球减贫最佳案例。9名教师和校友作为先进典型代表参加全国脱贫攻坚总结表彰大会。

张立杰强调，今年是中国共产党成立105周年，是“十五五”开局之年，全校上下正在深入开展树立和践行正确政绩观学习教育，奋力推进学校高质量发展，更加需要传承弘扬李保国同志的高尚精神。要学习李保国同志，铸牢对党忠诚的政治品格，做新时期的优秀共产党员，从他的先进事迹中汲取信仰力量，以党性立身做事，自觉把个人的奋斗融入到党和人民的事业中；要学习李保国同志，涵养心系群众的为民情怀，做矢志造福百姓的知识分子，从他的先进事迹中汲取榜样力量，将更多科研成果应用到生产一线，在服务人民中实现自身价值；要学习李保国同志，赓续不懈奋斗的愚公精神，做真抓实干的笃行者，从他的先进事迹中汲取精神力量，立足岗位职责，强化使命担当，锚定学校第十次党代会确立的发展目标和“十五五”规划任务，务实担当、久久为功，奋力推动学校高质量发展。

校长赵建军为“李保国式党支部”代表、“李保国式教师团队”代表、“李保国志愿服务队”代表颁授传承弘扬李保国同志高尚精神铭志牌，并带领师生代表庄严宣誓。铿锵有力的誓词在纪念石广场上空久久回荡，字字句句尽显师生赓续李保国同志高尚精神的坚定信念与决心。

邢台市委副书记陈冲讲述了李保国同志将毕生精力投入到山区生态建设和科技富民事业中，以及农大师生紧握“接力棒”，续写科技兴农、乡村振兴新篇章的历程，并表示将持续深化校地合作，聚焦山区振兴、产业升级等重点领域，共同推进乡村全面振兴。

李保国同志妻子郭素萍研究员，邢台、唐山、保定等基地代表和李保国志愿服务队学生代表分别追忆往事、讲述传承，表示一定接力奋进，把李保国教授未竟事业干到底，让太行山越来越绿，让他的精神代代相传。

纪念活动前，与会嘉宾和师生共同观看了“沿着李保国的足迹前行”主题展览。

上午10:40，河北农业大学原创舞台剧《太行的回音》在东校区综合楼礼堂首演。该剧以“人民楷模”李保国教授为原型，还原他扎根太行35载的坚守，展现了李保国教授在前南峪、岗底、绿岭等地科技扶贫的真实瞬间，展示了一代代农大人正循着他的足迹，在“太行山道路”上接续前行。

下午，由农业农村部科学技术司指导、中国农村技术开发中心联合河北省科学技术厅、河北省农业农村厅主办的优秀科技特派员河北巡讲活动在我校举办。全国优秀科技特派员李保国教授35年如一日，把毕生精力投入到山区生态建设和科技富民事业中，是全国几十万科技特派员的优秀代表。活动以巡讲的方式，缅怀李保国同志并学习他心系群众、扎实苦干、奋发作为、无私奉献的高尚精神。活动中，我校卢振启老师深情讲述了李保国教授传播先进技术、培育富民产业、带动农民增收的感人事迹。高洪波作为科技特派员代表分享了攻克设施蔬菜连作障碍，带领团队帮助菜农增产增收的生动故事。

同时，学校举办校地携手推进乡村全面振兴座谈会。与李保国同志生前服务的地方和基地代表，就产业培育、技术落地等方面合作进行了深入交流。
