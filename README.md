# 农助 AI

Windows 本地农业多智能体工作台，使用 React 19、TypeScript、Vite、Tailwind CSS 4、Lucide、React Three Fiber / Three.js、FastAPI、OpenAI 兼容 SDK 和 SQLite FTS5。

## 启动

双击 `start.bat`，随后打开 http://127.0.0.1:5173 。首次运行需要联网安装依赖，电脑需安装 Node.js 22.12+（或 24 LTS）及 Python 3.11+。`check.bat` 检查状态，`stop.bat` 仅停止记录在本项目中的进程并保留数据。

## 配置真实 AI

将 `.env.example` 复制为 `.env`，在本地填写 `DEEPSEEK_API_KEY`，然后重启。请在 DeepSeek 官方平台自行获取密钥并确认计费。不把密钥写进前端或聊天。未配置时，对话返回明确错误，不伪造分析。

文本问题、最近 12 条对话、关联地块与知识库命中片段会发送到配置的模型提供方。图片保存在本地；只有配置视觉模型并在对话勾选明确同意后，才发送图片。不要发送不愿与模型服务共享的敏感数据。

## 核心功能

- 全局原创 2D/3D 风格数字人“小禾”：鼠标/触摸拖动、边界约束、会话位置记忆、键盘移动、展开收起、真实后端对话、待机/思考/回答动画、浏览器语音能力。
- 独立 3D 农场：程序化土地、作物、道路、树木、农舍、拖拉机、池塘与栅栏，旋转缩放平移，点击选田，列表备用视图。
- SQLite 地块独立档案、生长阶段和状态、任务及 AI 管理计划、地块分析历史。
- 总智能体按任务关键词确定专业分工，可手动指定专业 Agent。专业 Agent 使用独立提示词及 JSON 结果，最后由总智能体进行一次真实流式综合。一次任务可调用多个专业 Agent；记录完成/失败状态，避免无意义的重复模型调用。
- 本地知识文件解析、分块、FTS5 trigram 检索、来源展示和删除。可重新导入更新后的资料。
- 对话历史、复制、重新分析、帮助反馈、多选追问补充、图片/视频本地上传与预览。

首次启动仅在空数据库中写入 6 块标记为模拟的示例档案和示例农事。不会覆盖已有数据。用户可编辑档案，或新增自己的真实地块。三维模型均为管理示意，未实现实地几何还原、卫星遥感、土壤传感器或真实数字孪生。

## 文件位置

`frontend/` 前端；`backend/` API 与调度；`knowledge/` 本地原始知识文件；`data/nongzhu.db` 数据库；`data/uploads/` 附件；`logs/` 服务日志；`scripts/` 启停管理；`docs/` 使用及测试说明。

## 验证

前端：`cd frontend` 后执行 `npm run build`。

后端：`cd backend` 后执行 `.venv\Scripts\python.exe -m pytest -q`。自动测试使用临时数据库，模型替身只测试调度流程，不能替代真实 DeepSeek 联调。实际测试范围见 `docs/TEST_REPORT.md`。

## 能力边界

没有可靠数据源时不输出实时天气、市场价格或当前有效政策。图像模型为可替换 OpenAI 兼容接口，默认未配置。语音识别可能依赖浏览器厂商在线服务，首次使用由用户决定是否授权。视频仅支持本地上传及预览，关键帧提取尚未实现。P2 的精细模型、季节变化、实时天气映射尚未实现。

服务默认只绑定 127.0.0.1，适合本机单用户使用；尚无账号、权限或公网部署配置，请勿直接暴露到公网。
